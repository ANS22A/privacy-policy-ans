الإصدار 1.6.0 المعتمد

سياسة الخصوصية وشروط الاستخدام

إضافة أنس القادري لتنزيل الملفات من واتس اب لمتصفح Google Chrome | آخر تحديث: سبتمبر 2026

1. مقدمة

تلتزم «إضافة أنس القادري لتنزيل الملفات من واتس اب» بحماية خصوصية المستخدمين وتوفير أعلى درجات الشفافية وفقاً لسياسات بيانات المستخدم في سوق Chrome الإلكتروني (Google Chrome Web Store User Data Policy). توضح هذه السياسة طبيعة البيانات المجمعة، والغرض منها، وكيفية حمايتها.

2. البيانات التي نقوم بجمعها (تحليل الأداء والجودة التشغيلية)

ابتداءً من الإصدار 1.6.0، قد تقوم الإضافة بجمع بيانات تشخيصية وفنية للأداء وإرسالها إلى قاعدة بياناتنا السحابية المشفرة بغرض مراقبة سرعة واستقرار عمليات التنزيل لجميع المستخدمين:

  • مؤشرات سرعة وأداء التنزيل: قياس زمن الاستجابة والمدة المستغرقة بالمللي ثانية (ms) منذ النقر وحتى إتمام الحفظ لضمان سلاسة الخدمة وسرعتها.
  • بيانات الملف الفنية: نوع الملف وامتداده (مثل PDF, DOCX, XLSX, PPTX, صورة) وحجمه، والمسار التقني المستخدم (التنزيل الصامت المباشر أو درع المعاينة).
  • معرّف جهة الإرسال: رقم هاتف جهة الاتصال المستخرج من معرّف الرسالة لغرض التحليل الإحصائي التشغيلي وتتبع جودة واستقرار التنزيلات بين الجلسات.
  • معرّف عميل مجهول (Anonymous Client UUID): رقم عشوائي يُنشأ محلياً لتمييز الجلسات الفريدة إحصائياً دون ربطها بهوية المستخدم الشخصية أو جهازه.
🔒 ما لا نقوم بجمعه نهائياً:
  • لا نقوم بقراءة أو فحص أو تخزين نصوص رسائلك أو محادثاتك الشخصية.
  • لا نقوم بفحص أو قراءة المحتوى الداخلي للملفات المحملة.
  • لا نصل إلى قائمة جهات الاتصال الخاصة بجهازك أو سجلات تصفحك.

3. الغرض من جمع البيانات واستخدامها

تُستخدم البيانات المجمعة حصرياً للأغراض التالية:

  • تحليل أداء وسرعة التنزيل واكتشاف أي بطء أو أخطاء برمجية في معالجة الملفات الكبيرة.
  • تحسين توافق الإضافة مع تحديثات WhatsApp Web المستمرة.
  • متابعة موثوقية وجودة الخدمة التشغيلية لكافة المستخدمين.

4. أمان البيانات والتخزين السحابي

يتم نقل كافة البيانات المشفرة باستخدام بروتوكول الأمان العالي HTTPS / TLS 1.3، وتُخزن البيانات في خوادم سحابية مركزية مؤمنة (Supabase) متوافقة مع أرقى المعايير العالمية لحماية وأمان البيانات (SOC2 Type II و ISO 27001).

5. عدم بيع أو مشاركة البيانات (No Sale of Data)

نلتزم التزاماً صارماً بأنه لا يتم ولا يجوز بيع أو تأجير أو مشاركة أي بيانات للمستخدمين أو أرقام الهواتف مع أي أطراف ثالثة، أو شبكات إعلانية، أو وسطاء بيانات، ولا تُستخدم البيانات في أي أغراض ترويجية أو إعلانية.

6. التحكم وخيارات المستخدم

يمتلك المستخدم كامل التحكم في الإضافة، ويمكنه في أي وقت تعطيل الإضافة أو إعادة تعيين سجل الملفات بنقرة واحدة من خلال نافذة الإضافة المنبثقة (Popup).

7. التراخيص وإخلاء المسؤولية

هذه الإضافة أداة مستقلة طوّرها المهندس أنس القادري لتعزيز الإنتاجية، وهي غير تابعة رسمياً أو مدعومة من WhatsApp أو شركة Meta.
